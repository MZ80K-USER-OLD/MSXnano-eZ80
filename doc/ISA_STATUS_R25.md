# R25の実装状態（過去のR21等の一覧より優先）

基準：R24.5のRAM併用版。FF化比較版は不採用。R25はTSTIOを追加したローカル検証済み候補で、GOWIN／実機は未確認。

| 区分 | 項目 | 状態 |
|---|---|---|
| 今回追加 | TSTIO | ED74 nn、ローカル検証済み。GOWIN・実機待ち |
| 未実装 | INIRX／INDRX／OTIRX／OTDRX | 次の追加I/O候補。R22の実装を移植していない |
| 一部未対応 | 混在CALL／RET／RSTの幅指定 | 正規形以外に保護HALTとなる組合せが残る。公式仕様との監査が必要 |
| 未実装 | 上位8bit=MBASEで選択するMSX窓 | 現行は上位00h判定。MBASEレジスタ自体は実装済み |
| 除外 | SLP | 拡張有効時NOP、スリープ／復帰なし |
| 除外 | 未定義命令TRAP | 実装しない |
| 除外 | 許可した5種以外の追加I/O | IN0／OUT0、INI2系等は追加しない。通常Z80 I/Oは維持 |
| 未完了 | 全対応命令の網羅検証 | オペランド・幅・フラグ・境界・割り込み・WAITの独立モデル照合 |
| 未完了 | 全体タイミング収束 | R24.5基準でもSetup／Hold違反あり |

RUNALLの全PASSは収録試験の合格であり、全eZ80互換認証ではない。実装済みのMBASE、MADL、ADL IM0／IM1／IM2／NMI、LDH／LDX、TSTを未実装へ戻して数えない。
