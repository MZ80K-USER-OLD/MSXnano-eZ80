# eZ80命令実装状況 — R23

追加I/O命令はINIRX/INDRX/OTIRX/OTDRX/TSTIOの5命令に限定。通常のZ80 I/O命令は維持。

R22.4実機基準: MR6/MX6/MEM/RUNALL全PASS、SOFARUNからスペースマンボウ起動・PLAY、Logic96%。R23はGOWIN・実機未確認。

## 集計

命令名単位: 実装済み72, 形式に制限・未監査あり6, 対象外19。全ISA形式の完成宣言ではない。

## 対象外・部分実装の扱い

SLPはNOP、未定義命令TRAPは実装しない。IN0/OUT0やINIM/OTIM系など、指定5命令以外のeZ80追加I/Oは対象外。通常Z80のIN/OUT/INI/IND/OUTI/OUTD/INIR/INDR/OTIR/OTDRを削除しない。

CALL/JP/RET/RETI/RETN/RSTの形式別監査は従来の命令一覧に記載した制限を継承する。未監査形式を今回のI/O試験だけで実装完了に変更しない。

資料: [Zilog eZ80 CPU User Manual UM007715-0415](https://www.zilog.com/docs/UM0077.pdf)。TSTIOのポート指定とフラグ、RXの固定DEポートを参照。

同名JSONにRTLのSHA256を収録。過去版一覧は履歴として残すが、現在のI/O方針はこのR23一覧を優先する。
