# R22以前の不一致条件とR22.4の確認範囲

過去のPASSは、修正との時間的な対応を示す。波形や使用イメージのハッシュで実機の原因まで確定していないものを、確定原因へ格上げしない。

| 時期 | 観測／変更 | R22.4での扱い |
|---|---|---|
| バス分離の前例 | 拡張アドレス下位FFFFがMSXセカンダリスロットへ到達する懸念 | 16bit MSXバスと24bitバスの分離を維持。07FFFFを含む試験とMSX側MREQ遮断を監視 |
| R11系列 A/B | 07FFFFで52→D6、080000でA6→73の報告。Bの再ビルドではMEM PASS | 要求受理時のアドレス・データ保持を維持。未確定の物理原因を一つにまとめない |
| R15→R15.3 | D3の020102でA2→A3、030000で96→97、CTL停止。再ビルド・ED内へのTSTデコード移動後に実機回帰PASS | デコード変更が既存命令へ影響し得る。R22.2のED内配置を維持し、命令の実行制御は今回変更しない |
| R18→R18.3 | 0A6000で31→33、55→03、実行ごとの値の変化。R17再ビルドMEM PASS。RST開始判定登録後にRW2/RS8/RUNALL PASS | 不良はRST命令を実行したときだけとは限らない。0A6000、31/CE、既存メモリ回帰を残す |
| R20.4 | SLP試験CASE0停止、PRE-SLPで0A6004の3E→31 | SLP自体とその前の準備転送を分ける。SLPは既定方針どおりNOPを維持 |
| R21 | IO2 CASE0停止、MEM最初の07FFFEで31→7E | 新IO2命令とFFFFの後続試験より前の不良。今回も新しい反復I/O命令を使わず診断する |
| R21.1 | HL一致、絶対／間接・複数回で同じ誤値。010100:31→20, CE→56、070100:A8/DE、07FFFE:28/1E、080000:70/86、0A6000:F0/26 | 各値は同じ実行へ混合せず記録。今回の行列へ同じアドレス群を入れる |
| R21.2/21.3 | 受理W記録、返答R記録、観測接続修正後にMEM/IO2/MR4/RUNALL・ゲームPASS | 追加FFや配線による配置変化でも症状が変わり得る。PASSのみで原因確定・STA合格としない |
| 65816風M2拡張の別系統事例 | 要求のない内部サイクルへ先行WAITを掛け、発生しないMREQ待ち | 現在はMREQ条件付きWAIT。内部サイクルで偽記録しない試験を維持。3回カウンタ解除を移植しない |
| R22.2→R22.3 | MR5のBEFORE_A1停止から、完了して31→00／CE→08へ変化。HL=010100、W/R要求記録=650100 | 停止と誤値を分ける。W記録はセル書込み成功の証明ではない。コントローラ内部の観測を追加 |

## 照合した実装

R21.3とR22.3の `memory_ez80.v` / `ez80_memory_bridge.v` は、R22.3で追加した観測用ポートとassignを除いて同じ。
デコード構造の変化、実捕捉の条件、配置配線の遅延は引き続き別々に検証する。
CPUのCE間引きでSDRAM/VDP側のHoldまで安全になるとは扱わない。SDC/CSTは変更しない。

## 今回の実機試験

- EZ80MR6: 010100の31絶対書込み＋DOS間隔、CE間接書込み＋連続処理。各行で絶対読出し2回とHL間接読出し2回。
- EZ80MX6: 010100/101/102/103、070100、07FFFE、07FFFF、080000、0A6000。上記2方式、計18行。
- 4つのbyte lane、64KB境界の前後、DOS前後、同じアドレスへの反転に近いパターン31/CEを含む。
- EX(SP)、複数byte境界・幅指定は既存EZ80MEMの回帰で継続確認。
- 完全なMSX/Nextor/VDPや配置配線後の遅延を再現した試験ではない。
