# 再構築R5：24bit ADD/ADC/SBC

## 基準と変更範囲

R4を基準とする。R4のGOWIN合成、実機動作、EZ80MEM P1: PASS、
試験後のSofaRun・スペースマンボウのプレイをユーザー報告として記録する。
R5の実機動作は未確認。

変更するFPGAソースはCPU本体とmcodeだけ。元T80、ラッパー、従来ALU、レジスタ下位16bit、
トップ、メモリブリッジ、SDRAM、GOWINプロジェクト設定、CST、SDCはR4と同一。
multicycleやfalse_pathは追加しない。実機レポートの違反を一律の制約緩和で消さない。

## 実装範囲

| 命令 | 長い指定での動作 |
|---|---|
| ADD HL,BC/DE/HL/SP | 24bit加算。SP入力はSPL |
| ADD IX,BC/DE/IX/SP | 24bit加算。SP入力はSPL |
| ADD IY,BC/DE/IY/SP | 24bit加算。SP入力はSPL |
| ADC HL,BC/DE/HL/SP | 24bit加算と入力C |
| SBC HL,BC/DE/HL/SP | 24bit減算と入力C（借り） |

49hまたは5Bhでデータ幅を長く指定する。40h/52hまたはプレフィクスなしでは従来16bit経路。
実機用の先行P1テストは49hを使用する。R5の追加内部試験では短い指定も確認する。
演算先はHL/IX/IY、SPは入力だけで、SPL/SPSを書き換えない。
ADC/SBCのHL自身を入力する場合も、書込み前の値を使う。
PC、SPS、割込みは従来の16bit Z80。ADL状態・命令フェッチ・CALL/RET・ADL割込みは未実装。

## フラグ

公式eZ80 CPU User Manual UM007715-0415のADD/ADC/SBCを基準にする。
https://www.zilog.com/docs/UM0077.pdf

- ADD：S/Z/PVを保持、N=0。Hはbit11からのキャリー、Cはbit23からのキャリー。
- ADC：Sは結果bit23、Zは24bit結果が0、PVは符号付きオーバーフロー、N=0。
- SBC：Sは結果bit23、Zは24bit結果が0、PVは符号付きオーバーフロー、N=1。Cは借り。
- ADCのHもbit11からのキャリー、SBCのHはbit12への借り。

Cが入る場合の24bit結果を確認し、16bit境界と24bit最上位境界を区別する。
未規定ビットX/Yはテストの契約に含めない。実装では結果上位バイト由来の値を設定する。
検証ではFをD7hでマスクし、文書化されたS/Z/H/PV/N/Cだけを比較する。
ADDでは入力S/Z/PVが結果と異なる状態でも保持されることを検査する。

## 捕捉・保持・反映

長い演算は命令フェッチの後、同じM1内の内部状態を延ばして実行する。
T4で左辺・右辺・入力フラグ・加減算の種類を専用レジスタへ捕捉する。
T4からT7までその値を保持し、T7で下位16bit・上位8bit・フラグを同時に反映する。
外部データバスで追加のメモリ読書きを行わない。PCの追加インクリメントも行わない。

加算と減算は、右辺の補数化と入力キャリーを切り替える共通の算術経路を使う。
これは論理構成の説明であり、GOWINでの具体的なLUT個数・配置・遅延を測定したという意味ではない。
従来の8bit ALUと16bit演算スケジュールは、短い指定とロック中の動作として維持する。
入力を捕捉してから結果反映するため、同一レジスタを両辺で使っても途中更新値を読まない。
CENが停止した場合、捕捉・反映も停止する。外部バス用の立上り／立下り許可は対にして停止する。
WAITは命令フェッチのT2で処理する。
実際のsetup/holdとクロック関係の成立はGOWINの配置配線後レポートで確認する必要がある。

## FLASH保存済みCOM

使用するのはP1/FLASHまとめと同一の `EZ80ALU.COM`。再生成しない固定入力。
SHA256:

`ea25357893f9d1e897e34e995bc132ac05c0c479a8c24d133f49910f3c95f0b3`

実行：`EZ80ALU /RUN`。
期待表示：`EZ80ALU P1: PASS`。
通常起動のPLANNEDは演算の合格ではない。E7E7hのE1hだけでも個別機能の完成は判定できない。
R5と組み合わせて/RUNする。

### 実機テストの24ケース

BC/DE/SPLを右辺にする3群で、以下の8ケースを行う。
24bit上位へのキャリー、FFFFFFh+1、7FFFFFh+carry、ゼロ結果、
上位だけが非ゼロの結果、借り、800000h-1の符号反転、同値同士の減算。
結果は060100h..060102hへPUSHした3バイトを独立して読む。
フラグは比較前にFLAGSへ保存する。SP入力のときは、演算後のSPL不変性も確認する。

破壊範囲：060100h..060102h、COM自身の低位SNAP/FLAGSなどのバッファ、通常SPS。
SP入力に無効バンクやFFFFFFhを用いるケースでも、演算の入力値として読むだけで、
そのSPLへPUSHする前に、テストがSPLを有効な退避領域へ設定し直す。
専用RAMの物理アドレスは論理+640000h。060102h→6A0102h。
VRAM/MegaRAMは直接試験しない。試験領域の既存内容は復旧しない。

### 診断表示とDOS

不一致では最初のADDR/EXP/ACTを保存する。ADDRは結果スナップショットまたはFLAGSの論理アドレス。
ACTは比較に使った取得値で、フラグの場合はD7hマスク後の値。
端子のアドレストレースではない。
DI中はDOS/BIOSを呼ばない。拡張ロック後に通常Z80のSPSで診断変換し、EIとBDOS9で表示する。
BDOS9モデル自身がEIすることを許容する。SPSとIX/IYの復帰も確認する。
NMIとADL割込みの試験ではない。

## 検証

現行集計は `verification_result.json`。以下の合計46シミュレーションを行う。

- R4までの回帰36ケース：ロック状態16、EZ80D3実行10、EZ80MEM実行8、追加データ試験2。
- 保存済みEZ80ALU.COM実行6ケース：正常4位相、結果上位バイトの破損、拡張無効。
- 内部の追加算術COM実行4ケース：通常、フェッチWAIT、クロック許可の一時停止、両者の組合せ。

内部COMは各実行で長い算術56件と短い算術8件を検査する。
クロック停止試験はCPUの1 T-state期間単位で立上り／立下りの許可を対にして止める。
半周期だけを独立に欠落させる入力は、このバスラッパーの試験条件にしない。
HL/IX/IYのADD、BC/DE/自己/SPL入力、ADC/SBC、入力レジスタ不変性、短いSPS入力を含む。
固定シードの数値と整数演算で期待値を求め、RTLの出力を正解として採用しない。
短いSPSの期待値はテストベンチの固定DOS風呼出し規約に依存し、この内部COMを実機へ追加保存する必要はない。
各長い算術のT7反映回数も確認する。自己入力やCEN停止による二重反映を検出する。

CPUはGHDLからVerilogへ変換し、実COMバイト列、簡易低位メモリ、SDRAMモデル、BDOS9で機能検証する。
実MSX-DOS全体、BIOS起動完了のシミュレーションではない。
部分Verilog構文確認では周辺VHDL・ベンダプリミティブをブラックボックス化する。
GOWIN合成・配置配線・タイミング・HDMI出力・実機動作は未確認。
