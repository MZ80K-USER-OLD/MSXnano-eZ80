# R37：LD A,I / LD A,R のフラグ修正

## 修正

R36を基準に、fpga/G80A_eZ80/t80_ez80.vhdのSpecial_LD処理だけを変更した。

| 項目 | R37 |
| --- | --- |
| Aへ読む値 | Iの下位8bit、または既存タイミングのR値 |
| S | 読み込んだ値のbit7 |
| Z | 読み込んだ値が0なら1、それ以外0 |
| H、N | 0 |
| P/V | IFF2（CPU内IntE_FF2） |
| C | 保持 |
| Fのbit3/5 | Z80互換動作として読込値のbit3/5を反映 |

I/Rの選択値を1つのIR_Load_Byteへまとめ、Aとフラグに同じ値を使用する。LD I,AとLD R,Aは従来どおりフラグを変えない。

書込みは従来のSpecial_LDのT3・ClkEn有効条件内で行う。RのM1による増加、R読出し時点、プレフィクス、デコーダ、命令の幅、ADL/MADL、メモリ/バス、ラッパー、リセット、GOWIN制約は変更していない。IR_Load_Byteは同じ条件内で代入して使う一時値で、新しいアーキテクチャレジスタやパイプライン段ではない。

INIのADLアドレス等、今回対象外のFUSE未一致は修正していない。

## 独立したフラグ検証

10,240件の完全な命令実行を検証。

- LD A,I / LD A,R：8,192件。全256読込値、両ADLモード、IFF1/IFF2を独立に0/1、C=0/1。期待値は命令仕様から別計算し、CEmuを使わない。
- Rは初期値を逆算して全256読込値を作り、低7bitの折返しとbit7保持を検証。
- LD I,A / LD R,A：2,048件。全256値、両ADL、相補的な入力フラグでフラグ非変更を検証。
- この独立試験はbit3/5も含むFの全8bitを比較する。

元の拡張FUSEでは対象2命令の64条件（native32、幅指定probe32）がすべてPASS。元の期待値や比較マスクは変更していない。

## 既存COM回帰の評価方法

今回の修正では、LD A,I/Rの後にPUSH AFで書くFの値も変わる。旧版との全バスデータ一致は正しい合格条件にならない。

実際にEZ80NMIの旧版比較は、アドレス04FFFBhとストローブが同一で、書込値だけがR37=40h、R36=42hとなった。この差はNフラグをクリアした結果。診断ログはR37_EXPECTED_NMI_AF_DIFFERENCE.log。

既存COM30本と、位相変更・CEN停止を含む追加12実行について、R37単独で実COMの自己判定を確認する。テストベンチのstatus=PASS、DOSへのSP/IFF/IX/IY/ADL/PC復帰、$FFFFとガード、拡張空間のMSXバス隔離、実SDRAM RTLとWAIT、BDOSのEI条件に関する既存assertは保持した。フラグを旧版と等しくするマスクをFUSEへ追加したのではない。

最終実行件数とログはdoc/R37_VALIDATION.json、doc/R37_evidenceを参照。

## 実機用テスト EZ80IRF.COM

`EZ80IRF /RUN`

期待表示：`EZ80IRF R37: PASS`

- I値/R初期値は00、01、7E、7F、80、FE、FF、55、AA。
- 各C=0/1でLD A,IとLD A,Rを実行し、36回の測定。
- IFF2=0（DI中）のハードウェア確認。IFF2=1やIFF1と異なる条件は独立シミュレーションで検証する。
- LD R,AとLD A,Rの間へ他の命令を入れず、Rの2回のM1増分を見込んで期待値を計算する。
- 定義済みフラグの比較マスクはD7h。入力フラグをFEh/FFhとしてS/Z/H/N/PVの更新とC保持を検証。
- ロックされたZ80モードのまま実行し、拡張解除やADLへの遷移、24bitメモリアクセス、IM変更は行わない。
- 測定中はDI。DOS/BIOS呼出しはしない。I/Rを戻してからEIを実行しDOS出力を呼び、DOSがEIする条件を考慮して終了時に保存した割込み状態へ戻す。
- Rは保存値へ戻した後、通常の命令取得で増加する。実行に要した分も含めて外部から見たRカウンタを過去へ完全復元する仕様ではない。
- 通常のMSX-DOSアプリとして実行する。独立IFF1/IFF2状態を持つNMIハンドラ内で呼び出すプログラムではない。

旧R36では`OP=I VAL=00 C=0 EXP A=00 F=40 ACT A=00 F=D2`を検出し、R37ではPASSとなることをローカルで確認する。メモリアクセステストではないため、FAIL表示は命令、測定値、C、期待A/F、実測A/Fを表示する。

既存の30COMとRUNALL.BATは変更していない。新しいEZ80IRF.COMだけをコピーして追加実行できる。RUNR37.BATは新テストを先に実行し、続けて従来RUNALL相当のコマンドを実行する。

## GOWIN/実機

本版のGOWIN配置配線、Logic使用率、タイミング、実機は未確認。通常プロジェクトはfpga/project_eZ80/MSXNanoTang20K_eZ80.gprj。設定と参照123件はR36と同一。

GOWINでビルド後、EZ80IRF /RUN、RUNALL.BAT、SOFARUNからスペースマンボウ起動・PLAYを確認する。比較には本版のimplを用いる。以前のR36の79%や実機PASSを本版の結果として扱わない。
