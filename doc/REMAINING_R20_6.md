# R20.6以降の実装優先順位

SLPは非対応・NOP、未定義命令TRAPもユーザー指定で非対応とする。完了条件から両方を除外する。

## 次の実装対象

| 優先 | 対象 | 現状と完了条件 |
| --- | --- | --- |
| 1 | INI2 / IND2 / OUTI2 / OUTD2 | 未実装。BCの16bitポートを使用し、既存単発I/Oと転送回路を共有。WAIT受理・C増減・B/HL・フラグを検証 |
| 2 | INI2R / IND2R / OTI2R / OTD2R | 未実装。DEのポートを使用しBCで反復。要求保持、反復境界の割り込み、BC/DE/HL幅と境界を検証 |
| 3 | INIRX / INDRX / OTIRX / OTDRX | 未実装。DEポートを固定して反復。優先2と状態・演算回路を共有 |
| 4 | 混在CALL/RET/RSTの未対応suffix監査と対応 | 正規形は対応済み。残るガードを公式仕様と照合し、有効な形式を個別に実装・試験。ガード対象を一律に不正命令と扱わない |
| 5 | 命令別の網羅検証、最終STA・実機回帰 | 既存RUNALLは部分集合。全対応命令のオペランド、幅、フラグ、割り込み、WAIT、規模を確認 |

優先1〜3は12ニーモニック。これが未実装項目の全数だと断定はしない。優先4と命令別監査により追加の不足が見つかる可能性がある。これらは次段階の計画で、R20.6に実装済みではない。

IN0/OUT0/TSTIO、INIM/INDM/OTIM/OTDMとその反復形など、I/Oアドレスの15:8を00hへ固定する追加命令は除外する。通常のI/Oで23:16を00hにすることとは別で、16bitのBC/DEポートを保持する命令まで除外しない。

既存のZ80 INI/IND/INIR/INDR/OUTI/OUTD/OTIR/OTDRは維持する。
