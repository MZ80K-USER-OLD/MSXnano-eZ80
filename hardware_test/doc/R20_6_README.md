# eZ80 restart R20.6 — SLP非対応・NOP化

## 採用方針

ユーザー指定によりSLPは非対応とし、拡張有効時のED 76をNOPとして扱います。未定義命令TRAPも実装対象から除外します。残る命令の実装を優先します。

この版は最後に全体の実機回帰が通過したR19.1をベースにしています。R20系のSLP停止・解除・専用リフレッシュ回路と、実機未確認のR20.5メモリ変更は含めません。R20.5候補は別配布の調査履歴として残します。R20.6のGOWINと実機は未確認です。

## 動作と変更範囲

| 状態 | ED 76の動作 |
| --- | --- |
| 拡張有効・Z80/ADL | NOP。IM・フラグ・汎用レジスタ・SPS/SPLを変更せず次へ進む |
| 拡張ロック・リセット直後のZ80互換 | 従来のIM1別名動作を維持 |
| 通常の76h HALT | 従来のHALTを維持 |

EDプレフィクスと命令バイトのフェッチに伴うPC/Rの更新は通常どおり行います。実チップとのT数一致は主張しません。幅プレフィクスは通常の命令境界で消費します。

R19.1に対するFPGA差分は次の2ファイルだけです。

- G80A_eZ80/t80_mcode_ez80.vhd: 拡張有効時のED76からIM1設定を除き、NOPとする。
- G80A_eZ80/g80a_ez80.vhd: 診断識別CE=02/CF=FDを追加。旧SLP対応識別値01/FEとは区別する。

新しいCPU状態FF、停止ゲート、復帰タイマ、メモリ回路、RAMは追加しません。16bit MSXバス/24bit拡張バスの分離、GPRJ、SDCはR19.1と同一です。R19.1由来のタイミング問題が自動的に解消するという意味ではありません。規模とSTAは再測定が必要です。

TRAP用の遷移やスタックフレームは追加しません。未定義命令は既存デコード動作を維持します。

## 実機テスト

ビルドは `fpga/project_eZ80/MSXNanoTang20K_eZ80.gprj` を使います。新しい版を別フォルダへ展開し、SynthesisからPlace & Routeまで実行してください。

1. `EZ80MEM /RUN` → `EZ80MEM P1: PASS`。
2. 新しい `EZ80NP6 /RUN` → CASE 0〜9の後 `EZ80NP6 R20.6: PASS`。
3. `RUNALL.BAT`、SofaRunからスペースマンボウの起動・PLAYを確認。

新しいimpl ZIPとLogic使用率も送ってください。SLP停止・復帰テストは以後の合格条件に含めません。旧SLP/REF診断を実行した場合のNOT READYは正常です。旧SP0診断も不要です。

EZ80NP6.COMは新規、12059バイト、CRC32 `83A3ADF2`。Z80/ADLそれぞれで無指定・SIS・LIS・SIL・LILの10ケースを実行し、AFとスタック、実行継続、DOS復帰を確認します。私有コードではIM2を設定しており、シミュレーションのCOM監視でNOP後のIM2保持も確認します。実機COM単体でIM2を独立に読み出して判定する試験ではありません。

DOS/BIOSがEIすることを想定し、表示前にIM1・Z80・MBASE=0・拡張ロックへ戻し、DOSから戻った直後にDIします。メモリ不一致はADDR/EXP/ACTを表示します。MSXのベクタやスロットレジスタを書き換える試験ではありません。

R19.1の旧28本のCOMは同一です。新規1本と、同プログラムを追加したRUNALL.BATを更新してください。テストZIPには29本をまとめます。

## 検証

GHDL変換後のデコード576条件と、HALT/IM1/IM2の4制御ケースが通過しました。実COM・メモリ・割り込み・ロック状態・幅プレフィクス等の61プロファイルも通過しました。実COMではZ80/ADL・5幅条件、WAIT・CE停止、READY/NOT READY・非対応・故障検出、DOS側EI・割り込みを確認します。実行した回帰ログはverification_r20_6へ収録します。

デコード検証と実COM/メモリ・割り込み回帰は別の粒度です。全命令を独立な正解モデルと照合した検証ではありません。配置配線後の遅延と実機の全周辺回路も再現しません。

## 残る実装

詳細はdoc/REMAINING_R20_6.mdとISA_AUDIT_R20_6.jsonを参照してください。

優先対象は、16bitポート上位を保持する追加ブロックI/Oの12命令です。単発のINI2/IND2/OUTI2/OUTD2から始め、反復形と固定ポート反復へ進めます。既存I/O・転送・幅制御・反復境界処理を共用する方針です。R20.6ではこれらを実装済みとしません。

その後、混在制御命令の未対応suffixを監査・実装し、命令別検証とSTA・最終実機回帰を進めます。SLP/TRAPと、I/Oポート15:8を00h固定にする追加命令は対象外です。
