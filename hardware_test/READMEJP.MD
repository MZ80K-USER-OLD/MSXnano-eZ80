# FLASH保存用 eZ80実機テストまとめ（R3 + 先行P1）

COMをZIP直下へ配置した。MSX-DOSから読める保存領域へファイルとしてコピーする。
このZIPはテスト用ファイル集で、FPGAのビットストリームやFLASH物理書込みイメージではない。
各COMは、既に配布した実体から変更せず収録した。

## 現在の確認用

| ファイル | 正常表示 | 実機確認 |
|---|---|---|
| EZ80D1.COM | EZ80D1 R1: PASS | R1で確認済み |
| EZ80D2.COM | EZ80D2 R2: PASS | R2で確認済み |
| EZ80D3.COM | EZ80D3 R3: PASS | R3で確認済み |

現在のR3の確認にはEZ80D3を実行する。R3TEST.BATも同じ内容。
D1/D2は以前の確認用として保存する。3本をまとめた新規実機試験を行ったという意味ではない。

## 対応RTL完成後に実行する先行テスト

| ファイル | 機能 |
|---|---|
| EZ80MEM.COM | 24bit絶対バイトアクセス、EX(SP) |
| EZ80ALU.COM | 24bit ADD/ADC/SBC |
| EZ80BLK.COM | ブロック転送・比較 |
| EZ80MUL.COM | MLT乗算 |
| EZ80LEA.COM | LEA/PEA |
| EZ80ADL.COM | ADL実行、native CALL/RET、Z80復帰 |

通常起動はPLANNEDを表示して終了する。PRECHECK.BATはこの6本を通常起動する。
対応RTLのリリースで実行対象を指定してから、例えばEZ80MEM /RUNと実行する。
引数は半角空白1つと大文字/RUN。現在のR3では/RUNで将来機能を試験しないこと。
/RUNは機能対応の自動判定ではない。
先行テストの試験本体は対応RTLで未検証であり、将来、修正版への差替えが必要になる場合がある。

## 診断表示の自己試験

EZ80LOG.COMは故意に期待値を不一致にする。期待表示は次のとおり。

EZ80LOG P1: DIAGNOSTIC SELFTEST stage L
ADDR=070800 EXP=97 ACT=96

この表示は診断の自己試験で、FPGA故障を示さない。R3のシミュレーションで確認済み、実機は未確認。
070800hの1バイトを破壊する。

## 共通事項

各機能テストは専用RAMの試験領域を破壊する。VRAM/MegaRAMの直接試験ではない。
DOS/BIOS呼出しはDIによるテスト区間の外。拡張をロックしてから結果を表示する。
ADDRは意図したCPU論理アドレスで、SDRAM端子の実測値ではない。
詳しい破壊範囲と仕様は同梱docの各資料を参照。
