# eZ80 全命令 FUSE形式データ v1

2026-11-02作成。Zilog eZ80 CPU User Manual UM007715-0415に基づく、独自形式 `EZ80-FUSE-ADL-v2` のテストデータです。公式FUSE配布物ではありません。

## 収録範囲

- 全97ニーモニック、883個の通常命令エンコーディング。CB/ED/DD/FD/DDCB/FDCBを含みます。
- 各エンコーディングにADL=0/1それぞれ8条件、計14,128件。
- 40/49/52/5Bによるサイズ指定を各ADLで2条件ずつ、計14,128件。
- IRQ/NMI、MADL、IM0/1/2、EI後の割り込み延期、HALTからの復帰の境界イベント試験34件。
- **合計28,290件**。全入力の総当たりではなく、全通常命令セルと代表条件の網羅です。

`coverage.csv` が全883エンコーディングの件数表です。未定義命令、Z80非公式命令、重複・異順序プレフィックス列は通常命令の網羅対象から除外します。ED30/ED70の旗のみ入力はUM0077のマップで空欄のため含めません。サイズプレフィックスは意味を持たない命令でも必ずトラップになるとは限らないことがUM0077のIllegal Instruction Traps節に記されています。そのような組み合わせもprefix probeとして区分しています。

## ファイル

| ファイル | 内容 |
|---|---|
| `tests.in` | 初期CPU状態と初期メモリ |
| `tests.expected` | 期待する最終CPU状態とメモリ |
| `cases.jsonl` | 命令バイト、実行命令数、外部イベント、比較マスク、注記 |
| `events.expected.jsonl` | 順序付きメモリ読み書き・I/O読み書き期待値 |

## 再生成

Python 3とGCCを用います。追加Pythonパッケージや電卓のROMは不要です。

```sh
python3 tools/build.py
python3 tools/generate.py
python3 tools/validate.py
```

期待値はeZ80X RTLと独立したCEmuコアから生成しています。コアはフラットな24bitメモリと決定的な16bit I/Oに接続し、命令・割り込み受付の完了境界で停止させます。参照ソースを同梱するため、このZIPだけで再生成できます。

## 検証の位置づけ

データ構造と全883セルの網羅性を検査し、8bit ALU、LD A,I/R、RST、IN0/OUT0、MLTについて、別記述の計算規則による694件の独立チェックを実施しています。

**本データ28,290件をeZ80X RTLで実行してPASSした、という成果物ではありません。実eZ80シリコンとの全件比較も未実施です。** 以前のv0.13 CPUでの1,402件PASSとは別の検証段階です。参照モデル由来の期待値には、独立チェックのない命令の実装誤りが残る可能性があります。

重要な補正：固定したCEmuのLD A,I/RはPVをIEF1から生成していますが、UM0077ではIEF2です。本生成器は出力PVだけを別の仕様規則で補正し、IFF1≠IFF2も試験します。RはCEmu内の回転した内部表現から正規化しています。詳細は`FORMAT.md`と`PROVENANCE.md`を参照してください。

## CPUへの適用

`cases.jsonl`の初期状態とプログラムだけをDUTに渡し、`steps`回実行して状態・指定メモリ・機能イベント列を採取してください。期待値をDUTに入力する必要はありません。全件を同じ順序で `{id,state,memory,events}` のJSONLに出力したら比較できます。

```sh
python3 tools/compare_dut.py dut_actual.jsonl --output dut_results.json
```

GHDLの各クロックの信号波形を、この機能イベント列と直接比較しないでください。ハンドシェイク成立時に一度だけイベントを採取するアダプタが必要です。クロック数、パイプラインの先読み、WAIT/CEサイクル数は本形式の比較対象に含めません。
