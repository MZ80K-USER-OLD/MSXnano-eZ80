# EZ80-FUSE-ADL-v2

## テキストの1ケース

1. ケースID
2. `AF BC DE HL AF2 BC2 DE2 HL2 IX IY SPL PC` の16進数
3. `I R IFF1 IFF2 IM HALTED 0`
4. `ADL MBASE MADL SPS`
5. `aaaaaa vv -1` のメモリ行を必要数
6. `-1` と空行

AF/AF2/SPSは16bit、BC/DE/HL/代替ペア/IX/IY/SPLは24bitです。PCはADL=0なら論理16bit、ADL=1なら24bit。短いコードフェッチの物理アドレスは`MBASE:PC`です。IはeZ80のLD I,HLを扱うため**16bit**、R/MBASEは8bitです。IFF/ADL/MADL/HALTEDは0/1、IMは0/1/2です。第3行末尾の0は予約で、Tサイクル数を意味しません。

v1とテキストの行配置は共通ですが、Iの幅、複数命令、I/O、外部イベントを拡張したため、v1用ハーネスへ無変更で投入できる保証はありません。メモリは24bit物理アドレス、未記載の初期バイトは00です。期待メモリには初期メモリと実際の書き込み先の和集合が含まれます。

## JSONL付帯情報

`cases.jsonl`は1行1ケースです。

- `instruction`: エンコーディングID。例`ED_4C`。
- `coverage`: `native`、`size_prefix_probe`、`external_event`。
- `code`: 即値・変位を含む命令バイト列。イベント専用ケースでは空。
- `steps`: 完全な命令または割り込みエントリを実行する回数。通常は1。リピート命令は反復全体の完了までを1とします。
- `events`: ステップ境界の入力。キーは0始まりのステップ番号、1=NMI、2=IRQ。IRQは入力後保持されます。クロック途中のタイミング試験ではありません。
- `io_seed`: 読み出しI/O値は`(port ^ (port >> 8) ^ io_seed) & 255`。割り込みデータバス値も同じseedを用います。
- `initial` / `memory`: 初期状態・初期メモリ。`tests.in`と一致します。
- `mask`: 比較するレジスタビット。記載のない状態項目は全有効ビット比較。AF/AF2の未定義ビット3/5は通常除外します。
- `notes`: ケース固有の未規定ビットや参照値の補正。

Rはパイプラインや取得サイクルの差を全命令で固定しないため、通常は比較から除きます。LD A,RではRとA、定義されたフラグを比較します。BITのS/PV、ブロックI/Oの未規定ビットはマスクします。マスクしたビットの生の参照値は、合否判定の根拠にしないでください。

`events.expected.jsonl`の`events`は`{kind,address,value}`の順序付き配列です。MR=データメモリ読み、MW=メモリ書き、PR=I/O読み、PW=I/O書き。先読み命令フェッチとリフレッシュは含みません。メモリは24bit、I/Oは16bitです。リピート中のイベントも全件記録します。

IRQ/NMIのIM、MADLによるスタックとベクタは参照モデルの結果を収録しています。IM0は外部が命令／ベクタを供給するため、ここで用いたseedの条件に限る結果です。電卓固有のASIC周辺回路、MSXのスロット／FFFFh、I/Oウェイトはモデルに含みません。
