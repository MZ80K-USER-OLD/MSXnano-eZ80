# 生成元と制限

- 仕様：Zilog eZ80 CPU User Manual UM007715-0415 (2015-04)。https://www.zilog.com/docs/UM0077.pdf
- 全命令セル照合：同書Opcode Maps Tables 106–112。
- 参照実行：CEmu https://github.com/CE-Programming/CEmu コミット `d7679d04c44741359b1f3a0444ff4eea99c34369`。
- 命令長／逆アセンブル：zdis https://github.com/CE-Programming/zdis コミット `7eb89e56d219bbca5ca5cd82c98dce69bd75004b`。
- 実行環境：Linux、GCC、Python 3。ネットワークやROMなしで再生成可能。

コアへの変更は、命令完了と割り込みエントリの完了でreturnする2か所、および違法命令トラップを記録するフックです。算術・アドレス・スタック命令の実行内容は変更していません。`tools/oracle.c`はメモリ／I/O／スケジューラ代替とCPU状態変換を提供します。

参照コアのRはビットを回転して保持し、IMの内部番号も外部の0/1/2と異なります。状態の入出力時に変換しています。短いPCは物理MBASE部分を外部状態から除いて16bit化します。これらはCPU命令の仕様変更ではありません。

確認した参照モデルの差異：LD A,I/RのPV生成元がIEF1となっているため、期待値生成後にUM0077に従ってIEF2へ補正しています。補正は`tools/generate.py`の`execute`関数に明示し、独立チェックでIFF1とIFF2が異なる条件も試験しています。

通常の命令セルは883個です：BASE248、CB248、ED135、DD95、FD95、DDCB31、FDCB31。プレフィックスそのものを単独命令とは数えません。未定義SLL、非公式CBレジスタ書き戻し、ED30/70などは含めません。オペランド値、全メモリ、全割り込み到来位相の総当たりではありません。

28,290件のうち全件について形式・ID対応・メモリ書き込み整合性を検査しています。694件は別に記述した仕様計算と比較しました。全命令の期待値が独立した第二実装やシリコンで確定したという意味ではありません。生成モデルの結果をモデル自身で再実行しただけの確認を、独立検証として数えていません。
