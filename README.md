# MSXnano T80 eZ80 再構築 R1 — データアクセスだけを検証

V34系を延長せず、同梱の元T80からCPUを作り直した評価版。
PC=16bit、通常SP(SPS)=16bit、別SP(SPL)=24bit。ADLモードでの実行・割込みはまだ実装しない。
BC/DE/HL/IX/IYの上位8bitを追加し、明示プレフィクスによるデータアクセスから確認する。

## 実機確認

1. ZIPを新しいフォルダへ完全に展開する。ZIP内や一時フォルダからビルドしない。
2. `fpga/project_eZ80/MSXNanoTang20K_eZ80.gprj` をGOWINで開き、全ビルドする。
3. 合成だけでなく配置配線・タイミング結果を確認し、このビルドのビットストリームを書き込む。
4. MSX-DOSで `hardware_test/EZ80D1.COM` を実行する。
5. 期待する表示は `EZ80D1 R1: PASS`。FAILならstage番号を記録する。

標準設定で拡張回路は存在する。リセット直後は実行時ロック状態で元Z80動作。
テストが明示的に解除する。ADL=1への移行は一切しない。
従来のEZ80RAM.COM/EZ80DIAG.COMは、この限定命令セット用の試験ではない。
GOWIN合成・配置配線・実機起動は未確認。黒画面の根本原因が解決したとは主張しない。

## MSX-DOS／BIOSと割込み

テストのDI区間ではDOS/BIOSを一度も呼ばない。
全アクセス完了→拡張ロック→EI→BDOS function 9で結果表示→DOSへRET、の順序。
DOS/BIOSがEIを実行することを許容し、呼出し前のDIが維持されるとは仮定しない。
将来、テスト途中に呼出しを追加する場合は、呼出し前にZ80状態へ戻して拡張をロックし、
復帰後にDIと必要状態の再設定を行ってからテストを再開する。
NMIはDIで禁止できず、この試験の対象外。

詳しい実装範囲・メモリ破壊範囲・検証の限界は `doc/RESTART_R1.md` を参照。
